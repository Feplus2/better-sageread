FAQ

常见问题

安装时 Windows 提示「已保护你的电脑」？

安装包未购买代码签名证书，SmartScreen 会拦截。点击「更多信息 → 仍要运行」即可。介意的话可从 GitHub Release 核对文件。

需要什么前提条件？

Better SageRead 面向 Windows 10/11 64 位；AI 能力需自备模型 API Key（如 DeepSeek，按量付费）；论文解析与扫描书转换需在 mineru.net 免费申请 Token。所有数据与密钥都保存在本机。四个组件工具跨平台。

我的笔记和数据会被上传吗？

不会。本地优先：数据库、书籍、向量库全部在本机；备份走你自己的 WebDAV（如坚果云）；API Key 存系统凭据保管箱，不明文落盘。本站也无 Cookie、无访问跟踪。

这套工具都是开源的吗？

是。Better SageRead 基于 xincmm/SageRead 发展而来，遵循 AGPL-3.0；Books Converter、Papers Converter、sageread-mcp、Zotero Brain 精简版均为 MIT。

截图里展示的论文和书是哪些？

论文为 Mukovnikov & Sousa《Gravitational waves from cosmic strings with friction》，arXiv:2605.22944，CC BY 4.0；书籍转换演示为公版书。在此致谢作者与开放许可。

以后怎么知道出了新版？

本页版本号自动同步 GitHub Release；Better SageRead 与 Books Converter 应用内也有「检查更新」。旧版升级直接安装新版即可。
