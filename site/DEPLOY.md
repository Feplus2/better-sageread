# 网站部署指南（腾讯云 · 手把手版）

这个网站由三部分组成，全部走腾讯云免费/低价套餐，支持微信/支付宝付款。
默认预览域名（3 小时有效）只适合自测；**正式访问需绑定自定义域名**——
未备案走境外节点即可用，启用中国大陆节点加速前才需要 ICP 备案：

```
访客浏览器
   ├── 网页本体  ←  EdgeOne Pages（免费静态托管；默认 *.edgeone.cool 域名是 3 小时
   │                临时预览链接，正式访问必须绑定自定义域名——见第 3/6 步）
   ├── 安装包    ←  腾讯云 COS 对象存储（"高速下载"按钮，按流量计费，每月几块钱量级）
   └── 备用直连  ←  GitHub Releases（"GitHub"按钮，海外用户与镜像兜底）
```

网页会**自动**从 GitHub 拉取最新版本号、文件大小和下载次数——每次发新版，
你只需要「GitHub 发 Release + COS 传新包」两个动作，网页一个字都不用改。

预计一次性耗时：40–60 分钟。

---

## 0. 准备：注册腾讯云并实名认证

1. 打开 https://cloud.tencent.com ，微信扫码注册。
2. 进入「账号中心 → 实名认证」，完成个人认证（身份证 + 人脸，几分钟）。
3. 后续所有服务用这一个账号即可。

## 1. 把代码推上 GitHub（如果 site/ 还没推）

网站放在本仓库的 `site/` 目录。EdgeOne Pages 可以直接从 GitHub 仓库部署：

```bash
git add site/
git commit -m "feat(site): 工具箱下载站"
git push
```

仓库公开私有都可以（私有仓库在 EdgeOne 授权 GitHub App 时勾选授权即可）。

## 2. 上传安装包到 COS（"高速下载"通道）

1. 控制台搜索「对象存储」→ https://console.cloud.tencent.com/cos
2. **创建存储桶**：
   - 名称随意（如 `sageread-dl`），地域选离你近的（如广州 ap-guangzhou）
   - 访问权限：**公有读私有写**
   - 多 AZ、版本控制、加密都可以不开
3. 进入存储桶 → 「文件列表」→ **上传文件**，把当前所有安装包拖进去
   （`Better.SageRead_0.2.0_x64-setup.exe`、`Books_Converter-v1.3-win64.zip` 等，
   **文件名保持和 GitHub Release 完全一致**，网页靠文件名自动匹配）。
4. 点任一文件 → 「详情」→ 复制「默认域名」的链接，形如：
   `https://sageread-dl-1250000000.cos.ap-guangzhou.myqcloud.com/Better.SageRead_0.2.0_x64-setup.exe`
5. 打开 `site/assets/js/config.js`，把域名部分填进 `cosBase`：
   ```js
   cosBase: "https://sageread-dl-1250000000.cos.ap-guangzhou.myqcloud.com",
   ```
   填好后网页上的「高速下载」按钮自动出现并指向 COS；留空时只有 GitHub 按钮。

**费用量级**（以控制台实际价格为准）：存储约 0.1 元/GB/月（你的包总共不到 0.5GB）；
外网下行流量约 0.5 元/GB——135MB 的安装包被下载 100 次约 13.5GB ≈ 7 元。
个人工具站一个月通常几块钱以内。

**防盗刷**：存储桶 → 「概览」可以设置用量告警（如每月流量超 20GB 发短信）。
桶里只放安装包、不放别的，风险就很小。

## 3. 部署网页到 EdgeOne Pages

1. 打开 https://console.cloud.tencent.com/edgeone/pages
2. **创建项目 → 导入 Git 仓库**，按提示用 GitHub 账号授权，选中 `Feplus2/better-sageread`。
3. 构建配置：
   - **根目录**：`site`
   - 构建命令：留空（纯静态，无需构建）
   - 输出目录：`/`（即根目录本身）
4. 点部署，几十秒后得到默认域名，形如 `https://xxx.edgeone.cool`。
   **注意：这个默认域名只是 3 小时有效的临时预览链接**，到期访问会报
   401 UNAUTHORIZED——在控制台项目页点「预览」可再授权 3 小时。
   它只适合临时自测；**正式对外访问必须绑定自定义域名**（见第 7 步，
   未备案也能绑，加速区域选"全球可用区（不含中国大陆）"即可）。
   之后每次 `git push`，网站自动重新部署。

> 备选：不想连 GitHub 也可以在创建项目时选「直接上传」，把 `site/` 文件夹
> （不含 `DEPLOY.md`）拖进去。
> 缺点是以后更新要手动重传。

## 4. 以后怎么发新版（一个动作）

1. **GitHub**：照常打 tag 发 Release（你已有的流程）。
2. **COS**：**不用手动传**——`cos-sync.yml` workflow 监听 Release 发布事件，
   自动把安装包同步进 COS 存储桶（Secrets 已配置；也支持 Actions 页手动
   触发 `workflow_dispatch` 补同步历史版本）。

完成。网页上的版本号、大小、下载按钮、GitHub 下载次数都会在
30 分钟内自动更新（做了缓存，防止 GitHub API 限流）。想立刻看到变化，
用无痕窗口打开网页即可。

## 5. 下载计数（仅 GitHub 口径）

网页上的「累计下载」数字 = GitHub Release 资产的真实 `download_count`（自动拉取，
无需任何配置）。**高速通道（COS）的点击不计数**——KV 边缘函数方案已于 2026-08-30
退役（KV 审批周期过长，且计数价值有限）。若日后想恢复全渠道计数，git 历史里有
完整的边缘函数实现（`edge-functions/api/dl.js`，检索删除前的 commit 即可）。

## 6. 防烧流量（攻击防范，正式上线前建议配置）

风险模型：安装包在 COS 按流量计费，攻击者反复下载可烧余额并挤占正常用户。
止损已有（余额上限），但**防御要做在边缘**——核心是让下载流量走 EdgeOne
（防护规则只在边缘节点生效；直连 `*.myqcloud.com` 域名任何规则都管不到）：

实际落地口径（2026-08-31，全部生效）：下载流量经 COS 的「自定义 CDN 加速域名」
接入腾讯加速网络——`dl.bettersageread.cn` → CDN 节点回源 COS 桶。子域名无需单独
备案（随主域名备案）。

已生效的配置（均经 API 落地/复核）：
1. **IP 限频**：同一 IP 每秒最多 10 次请求（正常下载一个包就 1 次；脚本烧流量直接
   被限住）——CDN `UpdateDomainConfig` IpFreqLimit。
2. **带宽封顶（二次止损）**：5 分钟窗口带宽超 100Mbps 即返回 404（80% 阈值先告警）——
   单个安装包 135MB 理论全速约 11 秒，100Mbps 对正常用户绰绰有余。
3. **HTTPS**：CDN 域名已绑免费 DV 证书（3 个月有效期，到期 SSL 控制台再申请一张
   5 分钟换绑；EdgeOne 侧边缘证书是自动续期的，CDN 域名的托管证书若日后出现
   「自动续期」选项优先换它）。
4. Pages 侧（网页本体）：自适应频控 + AI 爬虫处置等已在控制台开启。
5. 设备维度（同设备换 IP 反复烧）免费版做不到精确识别，IP+UA 组合近似；真有规模
   攻击再考虑 Bot 管理（付费）。

## 7. 绑定自己的域名（正式上线的必要步骤）

- **买域名**：腾讯云「域名注册」直接买（微信支付）。轻量服务器/DNS 专业版/
  SSL 证书等加购项都不需要（Pages 自动签发免费证书）。
- **绑定**：EdgeOne Pages → 项目设置 → 添加自定义域名 → 按提示加 CNAME。
- **备案**：只有当自定义域名要启用**中国大陆节点加速**时才需要 ICP 备案
  （腾讯云备案小程序在线办理，免费，约 1–3 周；前提是域名实名认证已通过
  且账号下有符合条件的备案云资源——最便宜的境内轻量应用服务器包月 3 个月
  即可，纯当备案门票）。
- **未备案的过渡期**：绑定域名时加速区域选「全球可用区（不含中国大陆）」，
  走香港/日本等境外节点，国内可正常访问（延迟略高），与备案流程不冲突；
  备案通过后再把加速区域改为含中国大陆，速度拉满。

## 8. 常见问题

- **默认域名访问报 401 UNAUTHORIZED？** 正常——`*.edgeone.cool` 默认域名是
  3 小时临时预览链接。控制台项目页点「预览」可续期 3 小时；长期访问请绑
  自定义域名（第 7 步）。
- **网页版本号没更新？** 有 30 分钟缓存；无痕窗口验证。GitHub API 匿名限额
  是每 IP 每小时 60 次，本站已做本地缓存，正常使用碰不到限额。
- **「高速下载」点了没反应/404？** COS 里的文件名和 GitHub Release 不一致，
  或 `cosBase` 填错（不要带最后那个文件名，也不要以 `/` 结尾）。
- **COS 流量异常？** 控制台「存储桶 → 数据统计」看明细，必要时开启 Referer
  白名单（注意别挡住下载器，先观察再限）。
- **想改网页文案/截图？** 都在 `site/` 里改完 push 即自动部署；截图放
  `site/assets/img/`，演示视频放 `site/assets/video/` 后在 HTML 里引用。
- **SmartScreen 拦截安装包？** 正常现象（未购买代码签名证书），
  「更多信息 → 仍要运行」。

## 9. 费用与用量运维（长期）

### 站点有哪些东西在花钱

| 项 | 量级 | 备注 |
|---|---|---|
| 域名 | 年费 | 注册商页面到期续费 |
| COS 存储 | ≈0.1 元/GB/月 | 全部包 <0.5GB，一年约 1 元，可忽略 |
| 外网下行流量（COS/CDN） | ≈0.2–0.5 元/GB | **主要变量**，按量后付费 |
| EdgeOne Pages / plan-free | 0 元 | 网页本体与加速套餐免费 |
| DNS | 0 元 | |

**量级锚点**：安装包 135MB，100 次下载 ≈ 13.5GB ≈ 3–7 元；每月 1000 次下载 ≈ 30–70 元。个人项目早期（每天几次到几十次下载）一个月通常 10 元以内。

### 流量包值不值得买

预付流量包约按量价的 8–9 折，但**当前体量不值得买**（总下载几十次）。
等月流量稳定超过 50–100GB（≈ 每天 15–30 次下载）再买：COS 控制台「资源包」
或 CDN「流量包管理」，选中国大陆通用流量包。买早了是纯浪费，按量先用着。

### 充值与防停服（必做）

1. 费用中心（console.cloud.tencent.com/expense）→ 充值 → 微信/支付宝，
   预存 50–100 元小额即可。
2. **余额预警**：费用中心 → 余额预警 → 设阈值（如 <20 元）短信/微信提醒——
   欠费停服前能收到提醒，网站不会无声无息挂掉。
3. 用量查看：费用中心 → 账单明细/用量明细（按产品）；COS → 用量统计；
   CDN → 统计分析。每周扫一眼。

### 异常流量应急

dl 域名已配 IP 限频（10 QPS/IP）+ 带宽封顶（100Mbps→404）。
账单若异常：CDN 统计看哪个域名/路径在吃流量 → 必要时桶转私有（下载全断，
先换链接）→ 排查攻击源。

### 定期动作清单

- 每 3 个月：CDN 证书换绑（免费 DV，SSL 控制台申请 5 分钟）
- 域名年费到期续费
- 公安备案号下发后补挂页脚（链接已在，等编号）
- 发新版：零动作（版本号/大小/下载数 30 分钟内自动更新）
