# SageRead 使用手册 · 阅读器

## 打开与标签页

- 在书架点书即打开阅读器，每本书是一个标签页。
- 标签栏支持横排（顶部）/竖排（左侧）：设置 → 常规里切换，竖排时可展开（220px）或折叠（48px）。
- 标签支持拖拽排序、中键关闭；横向模式下滚轮滚动、激活标签自动滚入视野。

## 阅读界面布局

- 中间是正文；右侧是 AI 阅读助手面板；另有笔记侧边栏（notepad）。
- 聊天栏和笔记栏位置可以对调：设置 → 常规 →「将聊天和笔记侧边栏位置对调」。
- 顶部有书籍标签条；阅读进度实时显示。

## 阅读设置（正文样式）

阅读器内的设置下拉（齿轮图标）可调整：
- **字号**：12–32，滑块步进 2。
- **字体**：内置预设（系统默认、寒蝉活宋体、经典衬线、现代无衬线、优雅楷体）+ 用户上传的自定义字体（设置 → 字体管理上传 .woff2/.ttf）。
- **行高**：倍数，默认 1.6。
- **配色**：正文的前景色/背景色方案（这是"书籍内部配色"，与应用界面的全局主题互不影响）。
- **阅读背景**：应用侧背景——默认纯色或照片场景（羊皮纸、星空、山脉、海滩、花卉），可自定义背景图文件夹里的图片；背景选择会多设备同步。
- 布局：滚动/翻页模式、页边距、分栏等。

这些设置都可以让全局助手代调（"字大一点""换个星空背景"）。

## 划线、想法与书签

- 选中正文文字可划线（高亮/下划线/波浪线样式，多色可选）并写想法（笔记）。
- 书内标注有三类：划线想法（annotation）、摘录（excerpt）、书签（bookmark）。
- 笔记侧边栏集中查看本书全部标注，点击可跳回原文位置。
- 划线与笔记可导出为 Markdown：让全局助手导出（"把这本书的划线整理成 md"），或在笔记面板操作。

## 阅读进度与多设备对齐

- 本地进度实时保存；开启增量同步后，进度约 25 秒内推送到云端。
- 对端拉到更新的真进度后：若你 60 秒内没翻页，阅读器自动跟上；否则只弹提示不打扰。
- 打开书时会先做一次单点快拉（约 1.5 秒超时），尽力对齐到最新进度。

## 阅读助手（书内 AI）

- 右侧面板即阅读助手，绑定当前这本书，可问答、总结、分析。
- 有 RAG 语义检索（需先向量化该书）：能精确引用原文位置。
- 支持思维导图生成、网络搜索。
- 快捷指令按钮在输入框附近，可在 AI 中心自定义（总结本章、分析观点、生成思维导图等）。
