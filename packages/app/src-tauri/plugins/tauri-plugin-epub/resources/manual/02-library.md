# 图书馆与书籍阅读器

## 图书馆（主页）

书架展示全部书籍卡片：封面/标题/作者、阅读进度、状态徽标。

### 导入与格式

- 「添加书籍」或拖放导入 `.epub` 文件
- PDF 书籍：点图书馆页头的「PDF 转 EPUB」，转换完成自动入库（引擎在 设置 → PDF 转换 里选）
- 同一本书重复导入会有明确提示：在库则提示已存在，在回收站则提示去回收站恢复，不会静默失败

### 卡片上的状态徽标

- **向量化圆环**：绿=已向量化（AI 可按内容检索本书）；灰=未向量化；红=失败；进行中的扇形环显示百分比
- **云端徽标**：表示文件只在云端（多设备同步场景），点击打开时自动下载
- **进度**：百分比条；在某位置停留约 30 秒以上才推进「真进度」，随手翻页不污染统计

### 右键菜单与多选管理

卡片右键（或「更多操作」）：打开、**打开文件夹**（直达该书的 EPUB/封面/元数据文件）、向量化、**翻译**（发起后台全书翻译，详见「书籍对照翻译」章）、编辑信息、删除等。「多选」进入管理模式后可批量移动/删除/向量化。删除进回收站，可从左侧导航「回收站」恢复或彻底清空。

### 标签

侧边栏标签区可创建标签、把书归入标签（一本书可属于多个标签）；「未分类」即无标签的书。

## 书籍阅读器

### 翻页与排版

- 支持**分页**与**滚动**两种模式，顶栏阅读设置里切换
- 字体系列（内置精选字体 + 字体管理导入的自定义字体）与字号（12–32px）可调
- 目录（TOC）面板按章节层级跳转；顶部显示当前章节与页码/进度

### 阅读区背景与配色

- 文字颜色：取色器自由取色，或一键「跟随主题」
- 背景三选一：**纯色**（默认）/ **内置照片场景**（羊皮纸、星空、山脉、海滩、花卉）/ **自定义图片**（设置面板里打开背景文件夹，放入自己的图片后刷新选用）
- 选照片场景或自定义图片时，「遮罩浓度」滑杆可调正文区的遮盖浓度——调低正文呈半透明，透出背后的图
- **动态壁纸**：视频壁纸来自全局主题（如内置的「怜烟」）。使用这类带视频壁纸的全局主题时，阅读区背景选纯色「默认」会自动半透明化，正文下面就是缓缓流动的壁纸（详见「外观、主题与个性化」章）
- 公式：书中残留的 LaTeX 源码（`\(...\)`、`\[...\]`）会在章节加载时自动用 KaTeX 就地渲染，无需任何设置

### 标注（左侧边栏「标注」tab）

选中文字后弹出操作条：高亮（多色/笔触样式）、写评论、Ask AI、复制。所有划线与评论列在标注面板，点击可跳回原文位置；可导出为 Markdown/HTML/PDF/图片。

### 笔记（左侧边栏「笔记」tab）

- 笔记是**长文 Markdown**：不是便签，是可以写一小篇文章的面板
- 列表是一张张笔记卡片；点进卡片即编辑/预览（同一区域切换「源码/预览」，有内容时默认预览）
- 每条笔记可填**标题**（可选）与**位置 tag**（弹目录选章节或手动输入），便于按章节归类排序
- 支持星标、右键菜单快捷导出/删除、「管理」模式批量导出为 Markdown 或批量删除
- 阅读助手可以把讨论产出直接整理进笔记（它会先给你看草稿再落笔）

### 其他

- 标签页休眠：不活动的书籍标签页会自动休眠释放内存，切回时秒醒并恢复原位（PDF 标签页除外——它没有位置恢复通道，永不休眠）
- 阅读时长统计：仅在真实阅读时累计，去「阅读统计」页查看
