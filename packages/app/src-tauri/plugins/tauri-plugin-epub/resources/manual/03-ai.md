# SageRead 使用手册 · AI 功能

## 两个 AI 助手

SageRead 有两个 Agent 上下文，同一套引擎、不同工具集：

- **阅读助手**：书内右侧边栏，绑定当前书，专注内容理解（问答/总结/RAG 检索/思维导图/网络搜索），工具是只读 + 本书 RAG。
- **全局助手**：主页侧边导航进入，是"全能管家"，拥有全局动作工具：书籍导入/删除/转换、标签管理、回收站、批量向量化、备份/同步、导出对话/笔记、切换主题与模型、调整阅读和界面偏好等。

## 模型配置（设置 → 模型提供商）

- 可添加多个服务商（OpenAI 兼容接口），每个服务商配置 baseUrl、apiKey，并拉取模型列表。
- **聊天模型**：对话用的主力模型，顶部下拉选择。
- **辅助模型**：生成对话标题、语义上下文、AI 标签、PDF 转换等轻量任务用，推荐便宜快速的模型；留空则跟随聊天模型。辅助模型选择会多设备同步（API 密钥永不同步）。
- **向量模型（Embedding）**：RAG 向量化和语义检索用，可配外部 API 或本地模型。
- 可以让全局助手直接切换："把聊天模型换成 xxx"。

## AI 中心（侧边导航）

四个页签：
- **技能**：自定义技能（提示词模板），可分作用域（阅读助手/全局助手/两者共享），可启停。
- **提示词**：查看两个助手的系统提示词（只读；修改需改源码 central-prompt.ts）。
- **快捷指令**：聊天输入框旁的快捷按钮，自定义名称/提示词/图标/作用域/排序。
- **MCP**：预留，后续迭代接入外部 MCP Server。

## 向量化（RAG 的前提）

- 书籍要先向量化，阅读助手才能语义检索原文。
- 全局助手可以代劳："帮我把未向量化的书全部向量化"；也可单本执行。
- 向量化耗时不等（取决于书长和 Embedding 速度），进度在图书馆可见。

## 对话管理

- 对话按作用域分：全局对话（全局助手）和书籍对话（阅读助手）。
- 对话可标星、改名、删除、多选导出（Markdown/HTML/PNG）。
- 全局助手能查询、标星、导出对话（"把星标对话都导出来"）。

## 全局助手常用指令示例

- "切换到深色模式" / "换成蛋糕主题"
- "总结我最近的阅读情况"
- "把《三体》的划线导出成 Markdown"
- "字大一点" / "阅读背景换成星空"
- "每天自动备份" / "立即同步"
- "恢复到上周的备份"（会先自动备份当前，重启后生效）
