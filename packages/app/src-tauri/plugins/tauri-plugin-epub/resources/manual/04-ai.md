# AI 助手与 Agent

Better SageRead 里有三个 AI 助手，各司其职：

| 助手 | 入口 | 干什么 |
| --- | --- | --- |
| 阅读助手 | 书籍阅读器右侧边栏 | 读懂当前这本书：章节问答、总结、解释、写笔记 |
| 论文助手 | 论文阅读器右侧边栏 | 读论文原文、跨论文检索、参考文献提取 |
| 全局助手 | 左侧导航「全局助手」 | 全能管家：导入/整理/转换/备份/设置……你在图形界面能做的它都能做 |

## 能力范围：它们具体会做什么

三个助手共享一批通用能力，再各挂一套专属工具。下面按「通用 → 各自专属」列出——很多能力不写在任何按钮上，直接用嘴说就能触发。

### 三个助手都有（通用能力）

**读与查**
- 查标注：把你说「我划过哪些关于 XX 的句子」，它去翻你的划线和想法（跨书）
- 联网搜索：需要外部资料时自己上网查
- 重看图片：聊天里分析过的图片，隔几轮还能调出来再看
- 手册问答：应用功能的疑问直接问它，答案引自本手册原文
- 对话召回：超长对话被自动压缩后，它仍能翻回早期问答原文——整理整场讨论成笔记时不会丢前文

**写与创作**
- **写笔记**：说「把这段总结写成笔记」，它把成稿 Markdown 笔记存进笔记面板（阅读/论文助手自动挂在当前书/论文下）。落库前弹确认卡，草稿先给你过目
- **写文件**：生成 HTML 页面、Markdown 报告、数据文件、脚本等，落在 Agent 工作区（设置 → Agent 里可改根目录）；支持局部编辑已有文件、读文件、按名找文件、跑命令——后三类操作按安全档位弹确认卡
- **导出划线**：把一本书的划线与标注导出为 Markdown 文件

**可视化**
- **思维导图**：说「把这一章梳理成思维导图」，输出可交互的导图
- **侧边栏实时预览**：回复里的 HTML / SVG / Mermaid / React 代码块会**自动**在预览面板渲染成图（Markdown 块不自动弹、防打扰，点一下代码块即可预览）——让助手「做个对比图表页」「画个流程图」，当场看到效果

### 阅读助手（针对当前书）

- 章节问答、总结、解释——没建索引也能直读当前章节正文兜底
- 配了向量模型后升级为**全书语义检索**：问法不必贴原文字面，意思相近就能命中（比如问「作者在哪讨论过官僚制」）

### 论文助手（针对当前论文）

- 读论文原文：目录、按节读、全文、元数据随口问
- 提取参考文献列表与图表
- 配了向量模型后支持**跨论文语义检索**（「哪几篇用了溶胶凝胶法」）

### 全局助手（专属工具最多）

图形界面能做的它基本都能代做：导入书籍/论文/字体、书籍与标签管理、回收站、PDF→EPUB 转换、向量化、论文文件夹整理、对话管理、技能与 MCP 与密钥保管箱的增删启停、应用设置修改、对话中途切换模型、同步管理、下载文件、解压、HTTP 请求（非查询类的外发请求会先弹确认卡）。

**上手最简单的方式**：直接说人话试——「把这一章整理成思维导图」「帮我把咱俩刚才的讨论写成一篇笔记」「做一个读书打卡的 HTML 页面」。

## 模型配置（设置页）

- **模型提供商**：配置各家 LLM 的 API Key（DeepSeek 等），Key 存系统凭据管理器，不明文落盘
- **向量模型**：embedding 服务（远程 API），支撑聊书问答、论文检索、使用手册问答
- **语音模型**：TTS 朗读相关
- **辅助模型**：轻量后台任务（如对话压缩摘要）用的小模型，建议配一个便宜快速的——它的思考强度自动控制：能关思考的模型自动关闭，关不掉的（如 GLM-5.3、Gemini 3、Hunyuan Hy4）自动取最低档，无需配置

## 思考强度（聊天设置）

支持思考的模型在聊天设置里按**原生档位**呈现选择器：有的模型是低/中/高档下拉，有的是预算滑块，恒思考模型只有档位没有「关闭」，不支持的模型自动隐藏；选「auto」则不下发任何参数、由模型自行决定。档位与能否关闭均按各厂商官方文档逐一登记（型号枚举表），新型号接入后自动适配。

## 向量化：盘活你的整个文献库

很多用户看到「向量模型」「向量化」会疑惑：为什么要额外折腾一个 embedding 服务？因为它不只是多了一个搜索框——它是把整条内容主线接入 AI 的地基：

- **语义检索**：向量化后的书籍与论文，助手按「意思」而非关键词检索。问「哪几篇论文用了溶胶凝胶法」不必记得确切措辞，概念相近就能命中
- **有证据的 AI 产出**：全局助手本身能读写本地文件；配上全库检索之后，它帮你写总结、做综述比对、出报告、辅助写作时，结论都能落回你库里的原文证据，而不是凭空编造。你的文献库从一堆静态文件，变成 Agent 可检索、可阅读、可引用的知识底座
- **手册问答**：连本使用手册都走了向量化——问全局助手「同步怎么开」，它能直接引手册原话回答（没配向量模型时自动降级为关键词检索，也能用）
- **对外开放**：搭配独立项目 **sageread-mcp**（一个 MCP server），你更顺手的其他 Agent 客户端（如 Claude Desktop、Kimi CLI）也能从外部检索这个向量库、读你的书库数据。语义检索的嵌入调用经本地加密通道转发给运行中的本应用执行——API Key 全程不出本应用，外部进程碰不到任何密钥

向量化按条目进行（卡片圆环显示状态与进度），存量内容可在多选/管理模式里批量向量化。向量库随备份一起走，换机恢复后检索立即可用，无需重建。

## 安全权限（三档，对三个助手一致生效）

在 设置 → Agent 里选择写操作安全模式：

- **严格（默认）**：工作区内读写静默执行；工作区外的读/写/命令执行都会弹确认卡由你裁决
- **宽松**：界外读也静默；界外写与命令执行仍弹确认卡
- **完全访问**：全部静默（仍有审计日志）

无论哪一档，**网络外发（POST 等）始终弹确认卡**。危险操作（删书、清数据）助手本身也会先问你。

## 对话

- 对话以「对话列表」归档：可星标、改名、删除、导出（Markdown/HTML/图片）
- 超长对话自动滚动压缩：早期内容压缩成摘要注入，**原始记录完整保留**，导出不受影响
- 公式渲染：助手输出的数学公式用 KaTeX 渲染（行内/块级/方程组均可）

## 技能（AI 中心 → 技能库）

技能 = 一份 SKILL.md 格式的操作手册，教会助手使用某个外部服务（如微信读书、ima 等）：

- 技能有作用域：全局 / 书籍 / 论文，匹配场景的助手才会加载
- 可以新建、导入（SKILL.md 文件或 GitHub 链接、zip 包）、启停
- 技能里的 API Key 不要明文写——让助手用密钥保管箱占位符 `{{secret:名称}}`

## MCP（AI 中心 → MCP）

接入外部 MCP 服务器扩展助手能力：

- **市场一键安装**：内置开源 MCP 市场清单，点安装即用
- **手动配置**：支持本地 stdio（npx/uvx 命令）与远程 HTTP/SSE 两种传输
- 配置里的密钥同样用 `{{secret:名称}}` 占位符引用，执行时才替换真值

## 密钥保管箱（设置 → 密钥保管箱）

集中管理供技能/MCP 引用的自定义密钥。密钥保存在系统凭据管理器（Windows 凭据管理器可按 `com.bettersageread.app` 查看），应用内只显示「已保存 ·•••」，模型只会见到占位符，永远见不到真值。

## 快捷指令与提示词（AI 中心）

- **快捷指令**：输入框旁的常用指令模板，一键发送
- **提示词**：阅读助手/论文助手/全局助手各有多套预设提示词，可自建、切换、导入导出

## 长期记忆

助手的工作区根目录下有 `memory.md`：你分享的偏好、决定，或你说「记住……」时，助手会写进去。工作区根在 设置 → Agent 里改（可给三个助手分别覆盖）。
