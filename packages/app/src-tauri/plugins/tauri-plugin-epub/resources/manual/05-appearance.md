# SageRead 使用手册 · 外观与个性化

## 明暗模式

设置 → 常规 → 外观：浅色 / 深色 / 跟随系统。全局助手也可以直接切换（"切换到深色模式"）。

## 全局主题（应用界面换肤）

设置 → 常规 → 外观 → 全局主题，内置主题：
- **默认**：中性浅色
- **羊皮纸**：暖棕纸质
- **森林**：沉静绿色系
- **红枫**：暖红色系
- **海洋**：冷蓝色系
- **薰衣草**：优雅紫色系
- **蛋糕**：奶油白底 + 蛋糕胚黄组件 + 糖浆粉与樱桃红点缀的撞色设计

每个主题都有浅色/深色两套配色，作用于书架、侧边栏、AI 问答区等应用界面（不影响书籍正文配色——那是阅读设置里的"配色"）。

## 自定义全局主题

- 点全局主题旁的「打开主题文件夹」，把自己的 `.css` 主题文件放进去，再点「刷新」即可选择；用户主题会带"（自定义）"标注，与内置同名时用户主题优先。
- 主题写法：覆盖 CSS 变量（`--background`、`--primary` 等）+ 按 `data-region` 语义钩子定制区域；文件首行注释 `/* @name 主题名 */` 声明显示名。详细开发指南见项目 docs/THEMING.md。

## 字体

- **界面字体**：跟随全局主题或系统。
- **书籍正文字体**：设置 → 字体管理，上传 `.woff2`（也支持 `.ttf` 自动转换）后在阅读设置里选用；字体文件可多设备同步。
- 可以让全局助手导入："把 D:\Fonts\LXGW.ttf 装成阅读字体"。

## 其他界面偏好

- **聊天自动滚动**：聊天时自动滚动到最新消息（设置 → 常规）。
- **侧栏互换**：阅读页的聊天栏与笔记栏位置对调（设置 → 常规）。
- **标签栏方向**：横排（顶部）/ 竖排（左侧，可折叠）。
- 这些都能让全局助手代调。
