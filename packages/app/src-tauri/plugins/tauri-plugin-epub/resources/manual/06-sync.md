# 备份与同步

设置 → 数据同步，填好 WebDAV 即可用。推荐坚果云（免费档足够，记得在坚果云账号设置里创建**应用密码**），也支持任意标准 WebDAV 服务。

## 两层机制：L1 备份 + L2 同步

| 层 | 干什么 | 何时用 |
| --- | --- | --- |
| **L1 完整备份** | 全量打包：数据库、全部书籍/论文文件、向量库、字体、背景、配置、Agent 工作区 | 换电脑搬家、定期保险 |
| **L2 增量同步** | 小流量实时同步：阅读进度、对话、笔记、标注、设置、文件资产 | 两台设备日常保持一致 |

**L1 是完备底座**：只开 L1 也能完整搬家——在 A 设备备份、B 设备恢复，填好各类 Key 后开箱即用（向量检索立即可用，不用重建）。L2 只是让双设备日常更顺畅的增益，L1 不依赖 L2。

## 备份（L1）

- 「立即备份」：全量打包上传。大文件按内容哈希去重——**同一文件永只传一次**，日常备份只有几 MB
- 支持后台执行：点了备份可以关掉设置页做别的，完成会有通知；「备份中」状态重开设置页也会保留，防重复发起
- 自动备份：可选每小时/每天
- 轮转保留最近 N 份（默认 10 份），云端不再被引用的旧资产自动回收

## 恢复

- 在列表选一份备份 → 恢复。恢复前自动把当前数据留档到本地（可回滚）
- 恢复完成后应用会重启；大包资产后台下载，下载期间点开某本书/某篇论文会插队优先下载它
- 资产包有内容哈希校验，损坏的包会被拒绝并提示重试，不会静默坏库

## 增量同步（L2，BETA）

- 开启后按选定频率（30 秒/5 分钟/30 分钟）推拉变更：进度、对话、笔记、标注、文件夹归属、设置主题等
- 阅读进行中**不同步进度**（防卡顿），停下来约 10 秒后随下一个周期推出去——这是有意取舍，不是 bug
- 删除会同步到对端（连文件资产与向量分片一起清）
- 大文件（书籍 EPUB、论文 paper.md 捆）走资产通道按需下载：对端先出现卡片（带云端徽标），点开时才下载

## 密钥不上云

API Key、WebDAV 密码等**绝不进备份包与同步数据**。换机后在 B 端重新填一遍同名 Key，技能/MCP 里的 `{{secret:名称}}` 引用自动恢复可用。

## 坚果云限额说明

坚果云免费档有月流量（约 1GB）与请求频率限制。本应用的备份做了流量优化（内容寻址去重+压缩），正常使用远够；但若短时间反复备份/恢复大库，可能触发坚果云 503 限流——稍等片刻再试即可，这是网盘侧的固有限制，付费档也只是放宽不是无限。
