# 常见问题与故障排查

## 数据与隐私

**Q：我的数据存在哪里？**
全部在本机应用数据目录（Windows：`C:\Users\<你>\AppData\Roaming\com.bettersageread.dev`）。书/论文文件在 `books/`，数据库在 `database/`，向量库在 `papers/`，配置为若干 JSON 文件。卡片右键「打开文件夹」可直达单条目的目录。

**Q：我的 API Key 安全吗？**
密钥全部保存在操作系统凭据管理器（Windows 凭据管理器，服务名 `com.bettersageread.app`），不写明文文件、不进备份包、不进对话上下文（模型只见 `{{secret:名称}}` 占位符）、不上云。

**Q：换电脑怎么搬家？**
A 机：设置 → 数据同步 → 立即备份。B 机：填同一个 WebDAV → 恢复最新备份 → 恢复后把 LLM Key、WebDAV 密码、Zotero Key 重新填一遍（密钥不上云是刻意的）即可完整使用。

## 功能使用

**Q：AI 回答里说「手册里没写」或答非所问？**
先确认向量模型已配置（设置 → 向量模型）；书籍问答需要该书已向量化（卡片绿环），论文同理。未向量化的书，助手会用「按目录读原文」兜底，答案范围会窄一些。

**Q：PDF 转 EPUB / 论文解析失败？**
看失败提示：网络问题（引擎是云 API，需联网，受代理设置影响）、额度耗尽（免费档每日页数限制）、文件损坏。换另一个引擎重试通常能绕过单引擎的怪癖。

**Q：备份/恢复报 503？**
那是 WebDAV 服务（如坚果云）的限流，等几分钟再试；频繁备份大库时更容易触发。应用内已有自动退避重试。

**Q：恢复备份后提示「资产捆校验失败」？**
说明某个资产包下载损坏——重试恢复即可（校验就是为此设的，坏包会被拒绝，不会静默坏库）。如果只有个别书缺文件，点开它时会自动从云端补下载。

**Q：公式显示为源码或红色报错？**
书籍与对话里的 LaTeX 公式会自动渲染；红色报错说明公式本身写法有误（多为转换产物瑕疵），对论文可尝试「重新解析」。

**Q：标签页太多卡顿？**
不活动的书籍标签页会自动休眠（PDF 标签页除外）。也可以在设置里关注「阅读统计」页的内存相关说明。
