# PDF 转换与 Zotero 导入

## PDF 转 EPUB（书籍）

图书馆页头「PDF 转 EPUB」打开转换面板：

- 选择 PDF → 开始转换 → 完成后自动入库；转换过程可取消
- 引擎二选一（设置 → PDF 转换）：
  - **MinerU**：表格密集的书更稳（跨页表合并），免费 1000 页/日
  - **PaddleOCR**：速度更快、图注绑定准，免费 3000 页/日
- 扫描版 PDF（无文字层）走 OCR；文字版 PDF 直接提取，效果更好
- 转换产物 EPUB 想取出来：书籍卡片右键 →「打开文件夹」

## 论文解析（文献库）

论文导入时自动走 Papers 解析管线（MinerU VLM 推荐）：正文转 Markdown、公式 KaTeX 化、大图光栅化重裁保持完整、图注/表注绑定锚点。

- 解析结果有质量闸（QC）：发现可疑痕迹（如缺页嫌疑、文字循环输出）会打标提示，可对单篇「重新解析」
- 换引擎或升级后想重转：卡片右键 → 重新解析（用源 PDF 重走管线）
- 某篇解析明显异常时，重新解析通常能自愈；持续异常请反馈开发者

## Zotero 同步

- 内置导入走的是**本地库**，不需要 API Key：「从 Zotero 导入」面板选择 Zotero 数据目录（默认自动定位 `~/Zotero`），即可扫描库按 collection 勾选批量导入
- 导入是幂等的：同一篇重复导入自动跳过；本地删除（含回收站清空）后可重新导入
- Zotero 侧的链接状态只存在本机，不随同步走——另一台设备上重新选择数据目录即可
- API Key 只有用 **Zotero Brain MCP** 时才涉及：配合 Zotero 桌面端（设置 → 高级 → 勾选「允许其他应用程序通过本地 API 通信」）可免 Key 只读；要让 Agent 帮你写入（如创建 collection），才需要在 Zotero 官网（zotero.org/settings/keys）创建带写权限的 Key，经 MCP 配置的 env 传入

## 网络下载（配合全局助手与外部 MCP）

- 全局助手内置「按 URL 下载文件」能力：你把直链丢给它（「下载这个 PDF 并导入文献库：https://……」），它会下载、解析、入库一条龙
- 「按题名检索论文并找到 PDF」**不是内置功能**——学术数据库检索与下载源需要搭配外部 MCP 服务（如配套的 Zotero brain 精简版 MCP，在 AI 中心 → MCP 接入），接上之后助手就能替你找论文了
- 网络下载走应用级代理设置（设置 → 网络代理，如有配置）
