# 外观、主题与个性化

## 明暗模式

设置 → 常规 → 明暗模式：浅色 / 深色 / 跟随系统。

## 动效模式

设置 → 常规 → 动效模式：完整动效（默认）/ 仅淡入淡出 / 遵循系统。
面板开合、卡片出入场、管理态切换等界面动效全部服从这个开关：低配机器或不喜欢位移动画时选「仅淡入淡出」（位移/缩放退化为纯淡入淡出，时长压短），选「遵循系统」则跟随操作系统的「减少动态效果」设置。此外，非「完整动效」档下，主题的动态视频壁纸（如怜烟）会自动冻结为静态帧——视频解码与逐帧合成停止、半透明观感保留，是动态壁纸主题在低配机器上的性能保险；切回完整动效即从冻结处续播。

## 检查更新与新版本提醒

设置 → 常规 → 检查更新：手动检查并确认更新（应用不会自动下载更新）。
有新版本时，顶栏设置齿轮与「检查更新」按钮会显示小红点，并标注版本号——点进去手动检查即可看到更新说明。

## 全局主题（应用整体配色）

- 设置 → 常规 → 全局主题：默认外观 + 内置主题（羊皮纸、蛋糕、怜烟、蒙德里安、莫兰迪）+ 你的自定义主题
- 主题覆盖应用全局：主页、阅读器外框、侧边栏、设置页
- **内置主题随应用打包、只读**，「打开主题文件夹」看到的文件夹里**没有**内置主题——那个文件夹是给你放自己的 `.css` 的（放好后点「刷新」，同名文件会覆盖同名的内置主题）

### 设计你自己的主题

全局主题就是一个 CSS 文件，欢迎自己动手做：

1. 复制教学模板 `parchment.css` 或视频壁纸模板 `lianyan.css`（在开源仓库的 `public/themes/` 目录下，github.com/Feplus2/better-sageread），改个文件名
2. 在文件首行注释里写 `/* @name 我的主题 */` 声明显示名，然后按注释与变量清单改颜色、透明度
3. 把文件放进主题文件夹（设置里的「打开主题文件夹」），点「刷新」选中即可

完整的变量清单、语义钩子（data-region）与示例片段见仓库的 **docs/THEMING.md** 主题开发指南。模板文件里也有逐段的调参注释（比如怜烟的透明度指南）。

## 阅读器外观（书籍/论文阅读视图内）

- 阅读区背景与文字配色：纯色 / 照片场景 / 自定义图片 + 遮罩浓度（详见「图书馆与书籍阅读器」章）
- 字号（12–32px）/字体系列、分页与滚动模式切换
- **动态壁纸**：「怜烟」这类带视频壁纸的全局主题下，阅读区背景选纯色「默认」即自动半透明、透出流动的壁纸；主题作者可用 `--reader-solid-alpha` 调节这个半透明的浓度
- 字体管理：设置 → 字体管理，导入自己的 .woff2 字体，书籍正文可用

## 通知与提示

- 操作反馈用右下角 toast 气泡；重要提示（备份完成、同步结果等）同时写进通知中心（顶栏铃铛），错过 toast 可以去铃铛里找回
- 通知是静默的：铃铛不显示数字红点，点开后才标注已读/未读

## 代理与网络

设置 → 网络代理：关闭 / 自定义 / 跟随环境变量，三档应用级 HTTP 代理（下载论文、访问 API 时生效，无需系统级 TUN 代理）。
