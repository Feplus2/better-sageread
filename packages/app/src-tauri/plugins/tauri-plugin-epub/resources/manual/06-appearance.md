# 外观、主题与个性化

## 明暗模式

设置 → 常规 → 明暗模式：浅色 / 深色 / 跟随系统。

## 全局主题（应用整体配色）

- 设置 → 常规 → 全局主题：内置主题 + 用户主题文件夹里的自定义主题（CSS 文件）
- 「打开主题文件夹」可以放自己的主题 CSS；「刷新」重新扫描列表
- 主题覆盖应用全局：主页、阅读器外框、侧边栏、设置页

想微调主题参数（比如透明度）？主题 CSS 文件里有带注释的可调参数段，直接改文件后刷新主题列表即可。

## 阅读器外观（书籍/论文阅读视图内）

- 阅读主题：正文区域的配色方案（见「图书馆与书籍阅读器」章）
- 字号/字体/行距/页边距/栏宽、竖排开关
- 阅读背景：纯色 / 图片 / 动态壁纸；正文遮罩浓度可调（调低 → 正文半透明，透出背景）
- 字体管理：设置 → 字体管理，导入自己的 .woff2 字体，书籍与全局界面都可用

## 通知与提示

- 操作反馈用右下角 toast 气泡；重要提示（备份完成、同步结果等）同时写进通知中心（顶栏铃铛），错过 toast 可以去铃铛里找回
- 通知是静默的：铃铛不显示数字红点，点开后才标注已读/未读

## 代理与网络

设置 → 网络代理：关闭 / 自定义 / 跟随环境变量，三档应用级 HTTP 代理（下载论文、访问 API 时生效，无需系统级 TUN 代理）。
