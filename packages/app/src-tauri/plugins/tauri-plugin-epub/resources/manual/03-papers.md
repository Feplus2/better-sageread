# 文献库与论文

文献库是论文的独立家园：PDF 导入后自动解析为 Markdown 阅读，保留图、表、公式与图注锚点。

## 导入论文

- **本地 PDF**：文献库「导入」选择 PDF，后台逐篇解析（进度可见，可取消）。解析引擎在 设置 → PDF 转换 里选（需先在同一页面填好对应 Token）：
  - **MinerU VLM（推荐）**：公式、图注、大图完整性最好
  - **PaddleOCR**：速度更快；复杂公式场景以 MinerU VLM 为准
- **Zotero 同步**：无需 API Key——「从 Zotero 导入」面板里选择 Zotero 数据目录（默认自动定位 `~/Zotero`），即可扫描本地库按 collection 选论文批量导入；同一篇重复导入会自动跳过
- 论文卡片右键：打开、向量化、翻译（已翻译的论文显示「重新翻译」= 全量重翻，会先弹确认）、重新解析、移动到文件夹、**打开文件夹**（paper.md、源 PDF、图片都在这里）、移到回收站

## 文件夹树

左侧是文件夹树（可多级），论文按文件夹归类；未归档的进「未归档」。卡片上的文件夹计数只统计在库论文（回收站里的不计）。

## 向量化与检索

- 卡片右上角圆环 = 向量化状态（绿/灰/红/进行中百分比）
- 向量化后，论文助手可以按内容语义检索；也可以在多选/管理里批量向量化
- **为什么要向量化**：它把文献库变成 AI 可检索可引用的知识底座，不止于搜片段——详见「AI 助手与 Agent」章的「向量化：盘活你的整个文献库」
- 检索默认不命中参考文献列表（References 小节已排除）；确需找某篇引用时告诉助手「连参考文献一起搜」即可
- 长综述全文总结不建议靠检索片段拼凑——直接让助手按目录逐节通读
- 重新解析后旧向量会被自动清除并标记为需重新向量化（避免检索命中旧正文的死块）；全局助手能识别这种状态，可以直接吩咐「把重解析过但向量化还是旧版本的都重做一遍」

## 论文阅读器

- 正文为 Markdown 渲染：标题层级、表格、公式（KaTeX）、图片
- **图表 tab（左侧边栏）**：以图注/表注为锚点的快速跳转列表（带中文翻译），点击直达对应图/表——组会汇报场景尤其好用；悬停可看缩略图
- **翻译**：整篇或分段中译，译文与原文对照；翻译结果落盘保存，下次打开直接可用。阅读器内发起的翻译，主页/文献库右下角会同步显示进度小卡（可取消，已翻部分会保存）
- **翻译徽标**：卡片标题旁的 Languages 小标——绿色 = 译本完整且为当前版本；黄色 = 译本陈旧（重新解析后旧译文自动隐藏，避免错配新正文；重新翻译即恢复）或不完整（上次翻译中断/部分批次失败，重新翻译可补齐）；未翻译不显示。悬停可看具体原因
- 阅读页翻译菜单的「翻译本文」是幂等续翻（只补没翻/内容变了的块，成本最低）；文献库右键的「重新翻译」是全量重翻（已有译文作废，额度消耗与首翻相当）
- **标注/笔记**：与书籍阅读器同款（划线高亮、长文笔记）
- 导出：可导出排版良好的 HTML/PDF/图片，公式与图表一并带出

## 论文助手（右侧边栏）

论文 scope 的 AI 助手：读原文（按小节）、跨论文检索、提取参考文献列表、写笔记。问公式含义、让它总结章节、对比多篇结论……直接说人话即可。

## 回收站

删除的论文先进回收站（与书籍共用回收站页），可恢复；清空回收站会连带删除文件与向量分片，不可恢复。
