# SageRead 使用手册 · 统计、PDF 转换与常见问题

## 阅读统计

侧边导航「阅读统计」页：阅读时长、次数等统计数据（按今天/近 7 天/近 30 天/全部）。全局助手也能直接回答："总结我最近的阅读情况"。

## PDF 转换（Books_Converter 整合）

- 侧边导航「PDF 转换」页：把 PDF 转成 EPUB 并入库，支持 OCR。
- 转换复用辅助模型；全局助手可代劳："把 D:\Books\paper.pdf 转成 epub 加进来"。

## 常见问题（FAQ）

**Q：AI 说"尚未配置向量模型"是什么意思？**
A：RAG 语义检索和向量化需要 Embedding 模型。去 设置 → 模型提供商 配置一个 Embedding（外部 API 或本地模型）即可；不配也能正常阅读和普通对话，只是没有语义检索。

**Q：为什么有的书问 AI 时引不到原文？**
A：这本书还没向量化。让全局助手"把这本书向量化"，或批量"把未向量化的书全部向量化"。

**Q：同步一直失败 / 提示 503？**
A：坚果云免费账户有请求限流。把拉取频率调低（设置 → 同步，或告诉全局助手），稍后自动恢复；不影响数据安全。

**Q：换新电脑怎么迁移？**
A：新设备安装后配同一个 WebDAV，开增量同步，等 1-2 分钟书库自动重建；书籍文件打开时自动从云端下载。也可以用 备份 → 恢复 开荒。

**Q：API 密钥会同步到其他设备吗？**
A：不会。apiKey、WebDAV 密码永远只存在本机，任何同步通道都不传输。

**Q：黑屏了怎么办？**
A：点顶部同步刷新按钮（等同 Ctrl+R）。仍不行则重启应用；开发版热重载时的偶发黑屏与数据无关。

**Q：全局助手和阅读助手有什么区别？**
A：阅读助手在书内，只读、专注本书问答；全局助手在主页，能执行全局操作（管理书籍、换主题、同步备份、调设置等）。

**Q：全局助手会乱删东西吗？**
A：删除书籍、恢复备份、重置进度等不可逆操作，它被要求先向你确认再执行；删除的书也会先进回收站而不是直接消失。
