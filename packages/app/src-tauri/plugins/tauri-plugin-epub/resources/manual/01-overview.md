# SageRead 使用手册 · 总览与图书馆

## SageRead 是什么

SageRead 是一款桌面电子书阅读器（Windows，Tauri 构建），核心能力：EPUB 阅读、AI 对话（书内阅读助手 + 主页全局助手）、多设备云同步、PDF 转 EPUB。

主界面左侧导航栏（侧边栏）从上到下：搜索框、图书馆、全局助手、AI 中心、PDF 转换、阅读统计；顶部右侧有同步刷新按钮和通知铃铛；底部是设置入口。

## 图书馆（主页）

书架展示全部书籍，支持网格/列表两种视图。顶部可按标签筛选，搜索框按书名/作者检索。

### 导入书籍

- 点击图书馆的「上传/导入」按钮，选择 `.epub` 文件（目前只接受 EPUB）。
- PDF 不直接导入：先去「PDF 转换」页转成 EPUB，转换完成自动入库；也可以让全局助手代劳（"把 D:\Books\x.pdf 转成 epub 加进来"）。
- 也可以把本地 EPUB 的绝对路径告诉全局助手，用 importBook 直接导入。

### 书籍状态与进度

每本书有阅读进度（百分比）与「真进度」机制：在某位置停留 ≥30 秒才推进真进度时间戳，随手翻页不污染统计。进度可多设备同步。

### 标签

- 侧边栏「标签」区可创建标签、把书拖入标签；一本书可属于多个标签。
- 「未分类」= 没有任何标签的书。
- 标签可以批量管理，也可以让全局助手做（"给所有科幻书打上科幻标签"）。

### 回收站

删除的书先进回收站（可恢复），超过保留期自动彻底清除。回收站在图书馆入口内，可恢复或彻底删除。

### 云端书目

开启增量同步后，书籍文件可上传到云端（内容寻址）。设置 → 同步 →「书籍文件同步」显示云端书目数量，可一键「上传全部」；仅在云端的书打开时自动下载。

## 顶部同步刷新按钮

侧边栏顶部右侧的圆形箭头按钮：
- 增量同步开启时：执行一轮完整同步（推送+拉取），完成后自动刷新整个页面；
- 增量同步关闭/未配置时：就是普通的页面刷新（等同 Ctrl+R）。

## 数据存放位置（Windows）

- 正式版：`%APPDATA%\com.xincmm.sageread\`
- 开发版：`%APPDATA%\com.xincmm.sageread.dev\`
- 下有数据库（database/app.db）、书籍文件（books/）、字体（fonts/）、主题（themes/）、同步配置（webdav-config.json、sync-state.json）。
