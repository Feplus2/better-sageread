# Better SageRead 使用手册 · 总览与快速上手

## Better SageRead 是什么

Better SageRead 是一款本地优先的桌面阅读器（Windows / macOS），把「读书」和「读论文」放在同一个书架里：EPUB 书籍、论文全文（PDF / XML）都能导入，阅读时随时跟 AI 对话。所有数据保存在本机，AI 服务由你自己配置。

两条内容主线：

- **图书馆（书籍）**：EPUB 为核心格式；PDF 书籍可经内置「PDF 转 EPUB」转换器入库
- **文献库（论文）**：论文全文（PDF，或 JATS/Elsevier XML）经解析管线转成 Markdown 阅读，支持文件夹树、向量化检索、全文翻译

## 主界面地图

- **左侧导航栏**（从上到下）：搜索框、图书馆、文献库、全局助手、AI 中心、阅读统计、使用手册；底部是回收站与设置
- **顶栏**：中央是应用名与标签页条（打开的书/论文以标签页呈现，不常用的标签页会自动休眠省内存）；右侧是同步刷新按钮与通知铃铛
- **阅读视图**：打开书籍或论文后进入阅读视图——正文居中，左侧边栏是标注/笔记（/图表）面板，右侧边栏是 AI 阅读助手

## 五分钟快速上手

1. **配模型**：设置 → 模型提供商，填入你的 LLM API Key（如 DeepSeek）；设置 → 向量模型，配置 embedding 服务——这是盘活整个书库的基石（详见「AI 助手与 Agent」章的向量化小节）
2. **配解析引擎**（读论文/转 PDF 书籍必需）：设置 → PDF 转换，填入 MinerU Token（在 mineru.net 免费申请，每日免费额度够日常使用）或 PaddleOCR Token——论文解析与「PDF 转 EPUB」都走这个云端引擎
3. **导入内容**：图书馆点「添加书籍」导入 EPUB；或把 PDF 拖到图书馆用转换器转 EPUB；论文到文献库导入 PDF / XML（自动解析）或从 Zotero 一键同步
4. **开始读**：点击卡片打开。右侧边栏是阅读助手，直接问「总结这一章」「解释这个概念」
5. **记与标**：选中文字可高亮、写评论、问 AI；左侧「笔记」面板写长文笔记（Markdown，可让 AI 帮你整理落笔）
6. **多设备**：设置 → 数据同步，填 WebDAV（如坚果云应用密码），「立即备份」即可完整搬家；开 L2 增量同步后两台设备自动保持一致

## 阅读统计与 AI 用量

主页的「阅读统计」页同时统计阅读与 AI 用量，右上角的时间单位（今日 / 本周 / 本月 / 今年 / 全部）一键切换，页内所有数字与图表全部跟随：

- **阅读四卡**：会话数、阅读时长、活跃天数、活跃日日均会话
- **AI 四卡**：输入 / 输出 Token、AI 请求数、参与对话的模型数（卡片与悬浮提示显示精确数值，明细表与图表刻度用 k/M 紧凑单位）
- **用量分布柱状图**：按模型分色纵向堆叠，横轴粒度随时间单位走（日→小时、周/月→天、年→月、全部→年）；悬浮显示模型名与精确数值
- **模型占比**：饼图 + 明细表（输入 / 输出 / 合计 / 占比）
- **阅读热力图**：以年为尺度，右上角可前后翻年，不受时间单位影响

AI 用量无需任何配置：每次 AI 回复自动记一行流水。统计自功能上线起累计，此前的历史对话不回填。

## 数据都在哪里

一切数据在本机应用数据目录（Windows：`C:\Users\<你>\AppData\Roaming\com.bettersageread.dev`）：书库文件在 `books/`、数据库在 `database/`、向量库在 `papers/`、配置为若干 JSON。密钥（API Key 等）不在这里——它们保存在系统凭据管理器，永不明文落盘。卡片右键菜单的「打开文件夹」可以直达某本书/某篇论文的文件目录。
