## 3. 当前关键设计（下个对话直接沿用）

### 3.1 Provider 协议
- Base URL 只决定端点，**协议由 provider 的 apiStyle 显式声明**；未声明时按 provider + 官方 host 推断，自定义代理保守走 chat。
- `apiStyle`: auto / openai-chat / openai-responses / anthropic-messages / gemini。
- 预置 provider 已填默认协议与推荐端点：
  - OpenAI → Responses
  - Anthropic → Messages
  - Gemini → Gemini 原生
  - DeepSeek → Anthropic Messages（https://api.deepseek.com/anthropic）
  - Kimi → https://api.moonshot.cn/anthropic
  - 智谱 GLM → https://open.bigmodel.cn/api/anthropic
  - MiniMax → https://api.minimaxi.com/anthropic（新增预置）
  - OpenRouter/Grok/小米/百炼/豆包/Ollama/LM Studio → openai-chat
- 自定义 provider 可在设置里选 API 格式；CherryIN 这类网关在 auto 下按模型前缀映射（openai/* → Responses、anthropic/* → Messages、google/* → Gemini）。
- 迁移：provider-store v6；已有 provider 按官方 host 补 apiStyle，自定义代理保持 auto。

### 3.2 图片通道
- **原生协议**：工具结果图片按官方 content 回传（toModelOutput），不挂 user 消息；已验证 DeepSeek 官方、CherryIN OpenAI Responses。
- **chat 通道**：仍需 fetch 层图片桥；总预算 700k dataUrl 字符、最新工具批优先、旧图换路径占位；仅作为 fallback。
- 工具：readImage（单张）、viewImages（1–6 张同一 tool result）；单图长边默认 1024、最大 1536，dataUrl 目标 ≤420k 字符。
- 线程/DB 落库前剥离 base64；重启后历史图需按路径重读。

### 3.3 检索范围
- 阅读助手：本书 / 图书馆 / 图书馆+论文库；论文助手：本篇 / 论文库 / 论文库+图书馆；全局助手不加下拉。
- 按每本书/每篇论文持久化，默认 current；范围同时约束 searchLibrary 与 readDocument/getDocumentInfo/getFigures/getCitationGraph。
- 旧工具模式隐藏下拉，并在描述中注明只部分生效。
