# docs/ 分层约定

- `plans/`：活跃施工卡与进行中的计划——新立项的施工卡、待办清单放这里；收官后移到 `archive/`。
- `audits/`：审计报告（带日期的审查结论与缺陷清单）。
- `archive/`：已收官的历史文档（已完成阶段的计划、被取代的路线图、调研存档），只读备查。
- 根目录只留长期有效的参考文档（契约、手册、方法论、愿景）与本导引。
