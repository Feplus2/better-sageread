## 1. 技术管线（demo 已验证，直接沿用）

| 环节 | 工具/参数 | 已踩平的坑 |
|---|---|---|
| 关键帧 | seedream-5.0-pro（`doubao-seedream-5-0-pro-260628`），t2i 2560×1440；后续帧用**图生图**改，场景一致性极好 | i2i 输出尺寸自适应（2560→2816），无碍 |
| 视频 | seedance-2.5（`doubao-seedance-2-5-260628`），首尾帧模式，`--dur 5 --resolution 1080p --wm false`，约 5-6 分钟/条 | **首尾帧模式必须 `--ratio adaptive`**（比例跟随首帧） |

| 页面 | canvas cover 适配（焦点偏左 0.22）+ 邻近帧兜底 pickReady + 惯性平滑 0.09 + 文字层与纱罩联动 | 元素 opacity 压平 3D 子树、CSS 动画 fill 覆写内联样式（v1 原型教训） |

## 2. 美术方向 v2：西式暖光书房

- **风格**：西式、收敛、典雅、素；暖色调、暖台灯；质感靠纹理/线条/动效，不靠颜色。
- **场景元素**：胡桃木书桌、象牙白亚麻布面精装书（无字）、黄铜钢笔、黄铜台灯、
  玻璃小花瓶+白色满天星、皮面古籍书架、麻绳牛皮纸卷轴。
- **色调**：暖象牙 + 胡桃木棕 + 黄铜点缀。**弃用朱砂红**（随"阅"字印章一并弃用——
  那不是我们的元素；品牌标识一律用原生软件图标 `packages/app/src-tauri/icons/icon.png`）。
- **构图铁律**：右侧 35–40% 保持干净墙面（文字列用）；**道具主体（书/卷轴/笔/花）整体偏左**
  ——书靠近画面左缘，为右侧文字列和左探截图卡让位（用户验收意见：否则会被盖住）；
  画面内不出现任何文字/水印。
- **卷轴在桌面上**（书的左后方），不在书架上——这样 converter tab 的卷轴展开动画
  直接在原位进行，无需多拍一段"取卷"过渡。
- **基调**：轻奢一点点——器物做工精致、光泽温润，但仍是克制素净的底子。
- **字体**：标题 Noto Serif SC/宋体系，西文小标 Georgia italic letterspaced caps。
- K0 西式试样已出（`site/prototype/assets/K0W.png`），prompt 存档 `.tmp-prompt-k0w.txt`。

## 3. Tab 架构：共享首帧，各展其卷

五个 tab：**Better SageRead（主）** / Papers Converter / Books Converter / sageread-mcp / zotero-brain-slim。

- **共享首帧**：同一桌面静物（合着的书、卷轴、钢笔、花全部在场），切 tab 零视觉跳变。
- **切换逻辑**：若动画未播完就切 tab，当前序列快速倒放（或推进）回首帧，再激活新 tab；
  新 tab 的帧组届时按需懒加载。
- **各 tab 动画母题**（视频只拍道具动作，文字截图一律 DOM 层）：

| Tab | 动画母题 | 段落规划 |
|---|---|---|
| SageRead | 书翻开 → 每功能块一次翻页 → 尾段合书回环（合书=翻开段倒放，零成本） | seg_open + seg_flip（复用） + seg_open 倒放 |
| Papers Converter | 卷轴徐徐展开 | seg_scroll |
| Books Converter | 钢笔在纸上书写（字迹渐显） | seg_write |
| sageread-mcp | 花叶生命周期（抽芽→绽放） | seg_bloom |
| zotero-brain-slim | 钢笔在索引卡片上书写（已确认） | seg_card |

- **tab 栏形态（已确认）**：左上角竖排小签，带原生软件图标。

- **帧预算**：通用翻页段只有一条、在所有小节切换处复用；合书用倒放。
  每 tab 新拍视频 ≤2 段。全站帧数预算见 §6。

## 4. 分镜脚本 v2（SageRead 主 tab）

原则修正（来自 demo 验收）：**书的动作与文字动作同时进行**（滚动段重叠），不再交错；
文字/截图信息占比上调，书退居氛围层。

```
p 0.00–0.05  首屏：共享首帧 + 主标题 + 原生图标
p 0.05–0.18  seg_open 书翻开；标题同时上移至左上角缩小为常驻标
p 0.18–0.30  块一 图书馆：文字列右 + 截图卡左探（与画面互锁）
p 0.30–0.36  seg_flip 翻页 + 块一切出、块二切入（同时）
p 0.36–0.48  块二 阅读器与主题
p 0.48–0.54  翻页 + 切换
p 0.54–0.66  块三 论文阅读（图表速跳）
p 0.66–0.72  翻页 + 切换
p 0.72–0.84  块四 笔记面板
p 0.84–0.88  翻页 + 切换
p 0.88–0.96  块五 AI 助手与检索
p 0.96–1.00  合书（seg_open 倒放）+ CTA「下载/开始」淡入 = 回到首帧
```

- 块内驻留时书页微颤（取 seg_flip 前 10% 帧往复）——"缓慢翻页"的氛围感。
- 同步与备份不单列块，并入块五尾部一句 + FAQ（见 §5 备注）。
- 其他 tab 结构从简：母题动画 1 段 + 2–3 个信息块 + 命令卡/下载卡。

**版权红线（截图选料规则）**：
- 论文只用 **CC BY / CC0** 的 arXiv 预印本（摘要页右下"License"可查；ML 顶会预印本大多是 CC BY），
  页脚或 FAQ 放一行署名（论文名 + arXiv 号 + 许可证）即合规；
  **避开** CC BY-NC / 任何 ND 变体、商业出版社论文（Science/Elsevier 等）。
  已确认可用素材：arXiv:2605.22944（宇宙弦引力波，CC BY 4.0，公式图表丰富）。
- 书籍只用**公版书**或开放教科书，不截商业书籍（教材出版社维权积极，不因非盈利而安全）。
  推荐：《Calculus Made Easy》（Gutenberg #33283，公版，公式密集，老书版式贴合书房美学）；
  OpenStax 系列（CC 许可，下载页挑 CC BY 的）。

## 6. 版式、性能与加载

- **版式**：文字列宽 38–42vw（demo 的 27vw 偏窄）；截图卡 16:10、圆角 8px、发丝细框，
  向左探出纱罩边界约 8vw，与场景互锁；奇偶块可 ±2vw 微调节奏。
  **canvas cover 焦点同步左移（0.22 → 0.15）**，与生成时的靠左构图配合，
  保证道具不被文字列和截图卡盖住。
- **帧预算**：SageRead tab ≈ seg_open 121f + seg_flip 60f + 倒放 0f ≈ 180f；
  其他 tab 各 ≈120f；全站 ≈660f。JPEG q0.8 → 约 95MB 总量，**但首屏只载首帧 +
  seg_open 前 30 帧（<8MB）**，其余闲时续载、切 tab 按需加载。
- **降级**：移动端 / prefers-reduced-motion → 静帧 + 分节文字页（沿用 demo 的 flat 模式）。
