## 2. 叙事主线：一主四辅，不做"全家桶平铺"

现有版本把五个产品平等铺开，主角失焦。我的建议：

**Better SageRead 占页面 60–70% 篇幅**，四个组件以「它的工作流」串起来：

```
        获取文献                    阅读与知识库                    开放生态
  Zotero Brain ──┐                                       ┌── sageread-mcp
  （发现·下载·入库）│                                       │   （书库读给 Agent）
                 ▼                                       ▼
  Papers Converter →→→ 【 Better SageRead 】 ←←← Books Converter
  （论文→Markdown）      书与论文同架 · AI 对话      （扫描书→EPUB）
```

首屏 Hero 只讲 SageRead 一件事；组件区以"四个齿轮"呈现，每个卡片一句话
+ 获取方式。访客 10 秒内应该明白：**这是一个阅读器，以及围绕它的一圈工具。**

## 4. 下载与获取通道（保持三通道，补组件形态）

| 组件 | 形态 | 通道 |
|---|---|---|
| Better SageRead | setup.exe / msi | COS 高速 + GitHub |
| Books Converter | zip 免安装（GUI / CLI 两包） | COS 高速 + GitHub |
| Papers Converter | 源码（pip 安装） | GitHub 仓库 + 命令卡 |
| sageread-mcp | npm 包 | `npx sageread-mcp` 命令卡 + 配置示例 |
| Zotero Brain | uvx 直跑 | `uvx --from git+...` 命令卡 |

命令卡做成"点击复制"小组件，比下载按钮更贴合开发者工具的习惯。

## 6. 美学方向（三选一，也可混搭）

**A. 书房纸韵（推荐）**：米白纸感底色（#faf8f4 附近）、衬线标题（Noto Serif SC）、
印章红/朱砂点缀（延续"阅"字 favicon）、细线框卡片、克制的 reveal 动效。
气质：书卷气、中文阅读工具的正统感，与你截的浅色截图天然搭配。
风险：做得不好会显老气——靠留白和现代排版救。

**B. 墨夜藏书**：深色底 + 暖光 accent，终端/代码元素点缀，geek 向。
气质：酷、开发者友好；风险：与浅色截图冲突（截图要配深色边框卡片罩住）。

**C. 现代 SaaS**：大留白 + 粗黑体 + 卡片矩阵（Linear/Vercel 风）。
气质：国际化、工具感；风险：千篇一律的"AI 产品落地页"味，丢失辨识度。

我推荐 **A 为主、深色模式自动跟随系统**（prefers-color-scheme，不做手动切换，
保持简单）。动效只用两种：滚动 reveal（渐现+上移 12px）与 hover 微浮起，
禁用视差、粒子、渐变字这三样 AI 味重灾区。
