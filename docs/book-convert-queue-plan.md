## 卡 1：图书转换窗口 → 双态任务台

**现状痛点（逐条核销）**：无队列（"更换"语义）；完成不自动导入；完成后 PDF 滞留列表；
拖入时遮罩盖全主页而非窗口。

**施工规格**：

- 窗口内容模型改为队列：拖入/选入多份 PDF 即排队入队（book-convert 通道 enqueue，
  每本一项）；队列列表每行 = 文件名 + 状态（排队/转换中带进度/完成/失败）+ 删除（×）。
- 「更换」按钮语义删除——用「删除→新拖入」替代（用户原话）。
- 入队即按通道串行泵跑（并发 1 维持）；完成 → **自动导入图书馆 + toast + 自动出队**；
  失败滞留队列带错误原因 + 可单独删除/重试。
- **双态**：窗口态 ⇄ 右下角通道卡（book-convert 卡片，bottom-right-stack 既有宿主）。
  窗口最小化 → 卡片态（进度照跑）；点卡片 → 还原窗口（队列现场在通道聚合里，零状态损失）。
  实现：窗口开/关状态机 + 卡片点击还原回调；已有任务在跑时关窗 → 自动转卡片态（不询问）。
- 拖入遮罩：只盖窗口本体（现在盖全主页是 bug 级错位）。
- 入口保持现状（转换器页/菜单入口不变）。

**验收**：多份 PDF 拖入排队连转（3 本实测）；完成自动导入自动出队；中途关窗 → 卡片态
进度延续 → 点卡还原窗口队列现场一致；遮罩范围截图对比；删除/重试/取消各路径；
tsc 零错 + 任务中心回归（scripts/test-task-center.mjs 11 项）绿。

## 卡 2：图书翻译入任务体系

- bottom-right-stack 渲染 book-translate 通道卡（聚合视图现成，照论文翻译卡样式；
  通道已在跑，只是没卡片）。
- AI 工具：`translateBook`（bookId/title 发现走 getBooks；幂等续翻默认、force 全量重翻）
  + 状态查询（复用 processPaper status 形态或并入）。提示词三处活清单同步（central/paper/
  reader，参考 readThread 进清单的做法）。
- **冲突矩阵**（同书互斥、跨书豁免）：book-translate × book-vectorize × book-convert
  同一 bookId 互斥（翻译中禁止向量化/重转换等）；不同书全豁免。注册进
  task-executor-registry 的冲突检查器（论文侧 ensurePaperTaskConflictChecker 同款先例）。

**验收**：阅读器发起图书翻译 → 主页右下角卡片可见进度、可取消；AI 工具「翻译这本书」
全链路跑通（小书实测）；同书双任务互斥提示语正确、异书并行无干扰；tsc 零错。
