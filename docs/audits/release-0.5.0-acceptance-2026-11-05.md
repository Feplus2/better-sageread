# Better SageRead 0.5.0 五项人工验收

日期：2026-11-05
状态：开发端技术准备与指定回归已完成，可以开始下列五项人工验收；这不等于已经发布，也不代替最终安装包与自动更新验收。

你不需要懂协议、Rust、CDP，也不需要逐家配置模型。技术测试由开发端完成，你只需判断：数据是否安心、操作是否顺心、产物是否正常、剩余风险是否愿意接受。

## 验收环境

- 应使用 `F:\MyProjects\SageRead-agent-followup` 对应的 **Better SageRead Preview**，从左侧「图书馆」开始即可。
- Preview 使用独立测试副本；不要拿日常唯一数据做写入测试，也不要使用移动端 worktree。
- 建议预留 30–45 分钟，按五项顺序做；任何一项不对都可以先记下，不必自己排查原因。

反馈格式只需要：

> 第几项 → 我做了什么 → 实际看到什么 → 我原本期待什么

## 1. 数据安心

- [ ] 原来的书、论文、对话、笔记仍在。
- [ ] 打开一本读过的书，阅读位置仍在；打开一篇论文，公式、图表和参考文献正常。
- [ ] 当前聊天模型、辅助模型、向量模型和主题没有被测试擅自换掉。
- [ ] 自定义提供商、代理地址和主动选择的端点仍保留。
- [ ] 打开一条旧对话继续问一次，能正常回答。

通过标准：没有丢数据，没有为了测试改坏你的日常选择。

## 2. 文件工作区

- [ ] 点文件夹入口，工作区在原助手位置打开，原顶栏按钮仍能点击；再点一次能回到对话。
- [ ] 返回对话后，聊天、滚动位置和输入草稿仍在。
- [ ] 打开目录和两个文件；内容区一次只显示当前标签，关闭目录不会关闭文件，关闭文件标签不会删除磁盘文件。
- [ ] 用 Windows 目录选择器选择一个测试目录，能进入子目录、返回上级和恢复共享工作区。
- [ ] 查看 Markdown 表格、CSV 和代码：列对齐、主题正常、代码不松散。

通过标准：入口找得到、标签不打架、文件不丢、返回对话不断片。

## 3. 聊天体验

- [ ] 连续调用工具时，执行中和结束后都默认折叠；展开后内容顺序正确，正式回答没有被吞进去。
- [ ] 普通回答不自行添加时间戳；问“今天几号”仍能答对。
- [ ] 开启「雾面-水流」后，开头、中段和结尾都有效果，结束后雾面与水迹消失，正文完整。
- [ ] 上翻加载更早消息，不会突然跳回底部；新对话内容垂直居中。
- [ ] 连续开关文件工作区和历史对话，没有明显过冲、回弹或装饰层挡点击。

通过标准：内容不丢、不乱跳、不遮挡，动画结束后干净。

## 4. 阅读核心与真实产物

- [ ] 问当前书“我读到哪了”或“这一章讲了什么”，回答对应当前位置。
- [ ] 问当前论文的一张图，回答基于真实图片，不只是猜图注。
- [ ] 打开开发端提前完成的 PDF 转换结果，正文、公式和图表基本可读。
- [ ] 打开开发端提前完成的一章翻译，译文可读，公式没有变成乱码。
- [ ] 查看已验证模型列表与未验证边界，确认没有把没有测过的厂商写成全部通过。

通过标准：核心阅读链路能产出真实结果，不只是 HTTP 请求成功或测试数字好看。
