# A/B 评测方案 v2（分桶 + 能力探针）

> 2026-10-22 · 取代 v1「所有题混在一起看平均 token」的做法
> 背景：v1 用总平均 token 当门槛，导致为了拉低未索引书的 token 给 readDocument 加了每轮硬上限——这是拿能力换指标，已全部撤回。

## 1. 原则

1. **分桶评测**：已索引文档（检索可用）和未索引回退（只能硬读）是两条物理路径，不能混在一个均值里。
2. **能力不被指标反向绑架**：文本读取不设每轮次数/字符上限；图片只保留单图分辨率控制（默认 1024，可升 2048），不设每轮张数上限。
3. **回退类只看正确率和引导**：未索引文档慢/贵是事实，不拿 token 当否决项；看它是否答对、是否主动提示「未建索引，建议向量化」。
4. **能力探针独立判定**：多图对比、深度考证这类任务只判正确性，不设 token/步数门槛，防止以后又有人为了均值把读取砍掉。

## 2. 分桶

### Bucket I：已索引文档（6 题）

| 题目 | 类型 |
|---|---|
| book-locate-ch3 | 书籍定位（书 A 已索引） |
| paper-figure-3-rational | 图表（论文 A 已索引） |
| position-summary-ch2 | 位置总结（书 A） |
| position-where-ch2 | 位置（书 A） |
| cross-doc-interface-design | 跨文献（论文 A+C 均已索引） |
| refusal-quantum | 拒答（书 A） |

指标：内容通过（facts+anchor）、干净通过（无外部搜索/命令行）、平均/中位 token、步数、describeTool、耗时、错误率。
门禁：内容 6/6；干净 6/6；中位 token 不高于 legacy +10%；平均步数 ≤ legacy；耗时 ≤ legacy +15%。

### Bucket F：未索引/回退（4 题）

| 题目 | 类型 |
|---|---|
| paper-figure-2-prussian | 图表（论文 B 未索引） |
| methods-dataset-scale | 方法（论文 D 未索引） |
| citation-ref-12 | 引用（论文 B 未索引） |
| unindexed-book-meaning | 未索引书（书 B，无向量库） |

指标：内容通过、「是否明确提示未建索引/建议向量化」的提及率。
门禁：内容 4/4；提及率 ≥50%（话术可不同，但必须让用户知道可以向量化提速）。**不设 token/步数门禁。**

## 3. 能力探针（只判对错，不设 token/步数门槛）

| 探针 | 说明 |
|---|---|
| multi-figure | 一次任务连续看 ≥3 张图并对比（如论文 A 图 2/3/4 分别设计什么） |
| deep-research | 需要 ≥4 次 readDocument 的跨章节考证（如福柯第三/四/五章的方法差异） |
| cross-doc-2plus | 两篇以上文档的对比，且每篇至少读 2 个位置 |

探针只验证「模型想深入读时不会被拒绝」；如果探针失败，禁止用降 token 的方式修，只能改检索/引导。

## 4. 跑法与记录

- 同一模型（deepseek-flash）、temperature 0、每题 3 次；fixtures 固定。
- 每轮输出：分桶表、分题 mean±sd、describeTool 计数、工具序列失败模式 Top5。
- A/B：legacy vs new；先分桶比较，再看总体（总体只作参考，不作门槛）。
- 记录目录：.tmp-eval-runs/ab2-<mode>/；报告：docs/audits/。
