## 4. 解读

- new 模式在跨文献（94k vs 165k）和图 3（31k vs 147k）上明显更省：readDocument 直接按章节读，不再用 readPaperFull/readAtReadingPosition 反复扩窗。
- book-locate 从 3 步降到 1 步（readDocument 直接命中章节），但单窗 6000 字符导致 token 不降。
- methods 两边都高（142k/149k）：模型用 5 个 12k 字符窗口读方法节，说明需要「检索命中 → 只读命中附近」而不是整节读。
- 未索引书是 new 模式当前最大回归：拿到 EPUB TOC 后仍用 8 次 readDocument 盲读（含 offset 20000/29000/34000），token 爆炸。根因是书籍 heading 读取没有稳定的「节内偏移」语义 + 模型不知道先读哪段。
- 单次结果方差大（同一 new 模式未索引题 92k 与 251k），必须 3 次重复。

## 5. 下一步（P1-3）

1. 修书籍定位：readDocument 对 book heading 返回「节内相对 offset + 节总长」，明确 next_offset 语义；heading 命中后禁止用整书 offset 续读。
2. 读取经济性 guidance：单题工具结果总量预算（如 ≤24k 字符），超过就停止扩读并作答；方法题改为「searchLibrary 命中片段 → 只读命中附近 2-4k」。
3. 3 次重复 A/B（new vs legacy），用 G1 门槛判定；达标后把默认 documentToolMode 切到 new，再进发版前回归。
